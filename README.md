# Siva Mandadi — Portfolio

Personal portfolio of **Siva Mandadi**, Senior .NET Full Stack Developer.

🌐 Live: https://sivamandadi16.github.io/

## What's inside
- `index.html` — page (Home, About, Skills, Experience, Projects, Contact)
- `style.css` — dark premium theme, fully responsive
- `script.js` — typing effect, mobile menu, scroll reveal, voice intro
- `assets/avatar.webp` — hero avatar
- `assets/intro.mp3` — tap-to-play voice intro
- `assets/Siva_Mandadi_Resume.docx` — downloadable resume

## Run locally
Open `index.html` in a browser, or:

```bash
python3 -m http.server 8000
# visit http://localhost:8000
```

## Deploy (GitHub Pages)
This repo is named `sivamandadi16.github.io`, so GitHub Pages serves it
automatically from the `main` branch root once the files are pushed.
